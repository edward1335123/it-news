docs/PLAN.md のフェーズ $ARGUMENTS を実装する。会話はクリア済みの前提なので、まず次を読んで状況を把握すること。

1. CLAUDE.md、docs/SPEC.md、docs/PLAN.md を読む
2. `git log --oneline -20` と `git status` で現在の状態を確認する
3. docs/reviews/ に前のフェーズのレビュー結果があれば読み、持ち越しの指摘を確認する

## 開始前のチェック
- 前のフェーズが `レビュー済` でなければ、作業せずに止めて報告する
- 対象フェーズがすでに `実装済` 以降なら、やり直すかどうかをユーザーに確認する
- 仕様が曖昧で判断できない点があれば、推測で進めずに質問する

## 実装
- PLAN.md に書かれた「作業」と「完了条件」の範囲だけを実装する。範囲外の改善は報告の中で提案するに留める
- 必要な依存パッケージは、実在してメンテナンスされている安定版を使う
- 完了条件にあるテストを書く

## 完了処理
1. `npm run check` を実行し、すべて成功するまで直す（フェーズ0で check を作る前は、作った範囲で検証する）
2. 完了条件を1つずつ確認する。ユーザーの確認が必要な項目は、その手順をまとめておく
3. PLAN.md の該当フェーズの状態を `実装済` にする
4. git にコミットする（`feat(phaseN): 概要` の形式。末尾に `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` を付ける）
5. 次の内容を日本語で簡潔に報告する
   - 実装した内容
   - 完了条件ごとの結果
   - ユーザーが確認すべきこと
   - 範囲外として見送った提案
   - 次の手順（`/clear` してから `/review-phase N`）
