## ユーザーが確認すべきこと

- connpass を取得するには、connpass の API キーを申請し、環境変数 `CONNPASS_API_KEY` に設定する（コミットしない）。フェーズ7で GitHub の Secrets に登録する
- `data/manual-events.json` は今は空。載せたい展示会・カンファレンスがあれば、docs/EVENTS.md の書き方に従って追加する
- events.json は git 管理外になったので、フェーズ7のビルドの前に `npm run collect:events` を実行する必要がある（news.json と同じ）
