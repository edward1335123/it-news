# 開発計画

状態の値: `未着手` / `実装済` / `レビュー済`
`/phase N` で実装すると `実装済` に、`/review-phase N` で合格すると `レビュー済` になる。
前のフェーズが `レビュー済` になってから次のフェーズに進む。

## フェーズ0: 土台
**作業**
- npm workspaces のモノレポ構成にする: `app/`（Vite + React + TS）, `collector/`（Node + TS）, `shared/`（共通の型）
- ESLint, Prettier, Vitest, TypeScript strict を設定する
- ルートの scripts: `dev`, `build`, `lint`, `typecheck`, `test`, `check`（lint・typecheck・test をまとめて実行）
- `.gitignore`, `.editorconfig`, `README.md`（起動方法）

**完了条件**
- `npm run dev` で空のトップ画面が表示される
- `npm run check` が成功する

## フェーズ1: データ形式とモック
**作業**
- `shared/` に SPEC 5章の型と、4章のカテゴリ・タグ定義（ID・表示名・色）を実装する
- 実行時バリデーション（zod）のスキーマを用意する
- `app/public/data/` に news.json（60件以上、全サブカテゴリ・日英を網羅）、events.json（20件以上、全種別・形式を網羅）、sources.json のモックを置く

**完了条件**
- モックJSONがスキーマ検証に通るテストがある
- `npm run check` が成功する

## フェーズ2: 画面とデザイン
**作業**
- タブバー（AI / セキュリティ / イベント / 保存）、ヘッダー（検索・設定への入口）
- サブカテゴリのチップ、記事カード、イベントカード、空の状態・読み込み中・エラーの表示
- デザイントークン（色・余白・文字サイズ）、ダークモード、セーフエリア対応
- モックJSONを読み込んで表示する

**完了条件**
- 幅 375px でレイアウトが崩れず、横スクロールが発生しない
- 4つのタブとサブカテゴリの絞り込みがモックデータで動く
- 主要コンポーネントの表示テストがある

## フェーズ3: 画面の機能
**作業**
- 既読管理、未読のみ表示、お気に入り・後で読む
- キーワード検索、ミュート語、情報源ごとの ON/OFF（設定画面）
- イベント: 種別・形式での絞り込み、.ics の生成とダウンロード
- 状態を端末内に保存する（IndexedDB または localStorage、読み書きは try/catch で囲む）

**完了条件**
- 再読み込みしても状態が残る
- 保存処理・フィルタ・.ics 生成のユニットテストがある

## フェーズ4: PWA化
**作業**
- manifest、アイコン（各サイズ、apple-touch-icon）、Service Worker（vite-plugin-pwa）
- オフライン時は前回のデータを表示し、最終更新時刻を出す
- iOS 向けの meta（standalone 表示、ステータスバーの色）

**完了条件**
- `npm run build && npm run preview` で Lighthouse の PWA 要件を満たす
- iPhone で「ホーム画面に追加」して起動できる（ユーザーが確認する）

## フェーズ5: ニュース収集
**作業**
- `collector/` に RSS 取得、正規化、重複除去、分類・タグ付け（キーワード辞書）、注目度計算、30日での削除
- SPEC 6章のニュース情報源を `sources.json` に登録し、フィードURLを検証する（取得できないものは理由を記録して除外）
- 出力先を `app/public/data/news.json` にする。モックは開発用に残す

**完了条件**
- `npm run collect:news` で実データの news.json が生成され、画面に表示される
- 一部のフィードが失敗しても全体は止まらず、失敗はログに残る
- 分類・重複除去のユニットテストがある

## フェーズ6: イベント収集
**作業**
- connpass API v2（キーは環境変数 `CONNPASS_API_KEY`。未設定ならスキップ）, Doorkeeper API, TECH PLAY
- 東京＋オンラインで絞り込み、IT・AI・セキュリティ関連の判定、種別の推定
- 展示会・カンファレンスを手動で管理する `data/manual-events.json` と、主要な公式サイトからの取得

**完了条件**
- `npm run collect:events` で events.json が生成され、画面に表示される
- APIキーがなくてもエラーにならない
- 絞り込み・種別推定のユニットテストがある

## フェーズ7: 自動化と公開
**作業**
- GitHub Actions: 毎時の収集 → ビルド → Cloudflare Pages へのデプロイ
- Cloudflare Access でメールOTP認証を設定する（手順を `docs/DEPLOY.md` に書く）
- Secrets の一覧と設定手順をまとめる

**完了条件**
- push と cron の両方でデプロイされる
- 認証なしではアクセスできない（ユーザーが確認する）

## フェーズ8: プッシュ通知
**作業**
- VAPID 鍵の生成手順、アプリでの購読処理（購読情報を表示してコピーできるようにし、Secrets に登録する）
- `collector/notifier`: 通知条件の判定、送信済みの記録、静かな時間帯、1時間あたりの上限
- 設定画面: 通知の ON/OFF、注目キーワード

**完了条件**
- テスト送信が iPhone に届く（ユーザーが確認する）
- 通知判定のユニットテストがある
